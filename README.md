# 🌐 Portfolio Website

This is my personal portfolio website showcasing my skills, projects, and services as a Computer Science student and aspiring software developer.

The website is hosted using **GitHub Pages**.

## 🚀 Features
- **Smooth scrolling navigation**
- **Sticky navigation bar**
- **Responsive layout** (mobile-friendly)
- **Clean and modern design**
- **Interactive animations**
- **Project showcase**
- **Contact form**

## 🛠️ Built With
- **HTML5** – Structure and semantics
- **CSS3** – Styling and animations
- **JavaScript** – Interactive functionality

## 📂 Website Sections
1. **Home** – Introduction and welcome section
2. **About** – Background, education, and skills
3. **Projects** – Portfolio of completed projects
4. **Services** – Offered development services
5. **Contact** – Contact form and information
